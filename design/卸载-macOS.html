拖入废纸篓 = 卸载完成

这是 macOS 的常规卸载方式，Vox 不内置任何卸载程序。清空废纸篓后应用即被移除。

会留下什么（均为用户数据，可选清理）

• 内容仓库（git clone 的目录）——不受任何影响
• ~/Library/Application Support/Vox —— 文章索引、缩略图缓存
• ~/Library/Caches/com.codewf.vox · …/Preferences/com.codewf.vox.plist
• 钥匙串中的 GitHub PAT（保留则重装免配置）

如需彻底清理（可选）
rm -rf ~/Library/"Application Support"/Vox \ ~/Library/Caches/com.codewf.vox \ ~/Library/Preferences/com.codewf.vox.plist security delete-generic-password -s com.codewf.vox # 钥匙串 PAT
