Avalonia 12 桌面应用开发实战：从零到发布

跨平台桌面开发在 .NET 世界里终于有了趁手的答案。本文以一个真实上线的应用为例，从项目创建讲到三平台打包发布。

为什么是 Avalonia 12

相比上一代，Avalonia 12 在渲染管线、无障碍与 Native AOT 兼容性上都有实质进步：

  • 单一 XAML 代码库覆盖 Windows / Linux / macOS；
  • 主题系统与 Semi / Ursa 生态兼容；
  • 裁剪与 AOT 发布体积进入可用区间。

先让它跑起来，再让它像样起来，最后让它发布出去。

最小可运行骨架

var builder = AppBuilder.Configure<App>()
    .UsePlatformDetect()
    .With(new FontManagerOptions { DefaultFamilyName = "Segoe UI" });
builder.StartWithClassicDesktopLifetime(args);

平台产物要点
WindowsEXE / 自包含Trimmer + 单文件
LinuxDEBx64 / arm64 双架构
macOSDMG签名与公证
