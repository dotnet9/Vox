# Vox 产品需求基线

状态：**V1 工作区与主要交互范围已冻结（2026-10-31）**。主原型为 [design/Vox.html](../design/Vox.html)，页面职责以 [信息架构](信息架构.md) 为准。本文描述真实产品行为；原型演示数字不构成需求。

## 产品定位

Vox 是面向技术作者的桌面写作环境与内容仓库治理/发布工作台。首要服务 CodeWF 的 Assets.Dotnet9 内容仓库，逐步支持通用文章仓库。写作、文章与图片管理、站点数据、Git 同步、多平台分发构成一个本地闭环。

Vox 与 Vex 独立维护：Vex 是通用 Markdown 编辑器，Vox 是内容仓库管理和分发工具。

## 核心用户流程

1. **写作**：新建文章 → 编辑 Markdown → 实时预览/思维导图 → 元数据与图片维护 → 自动保存。
2. **资产治理**：文章库/图片库检索 → 查看元数据和引用关系 → 修复或清理 → 通过 Git 审核变更。
3. **站点发布**：查看 Git 变更 → diff → 提交并推送 → 查看历史。
4. **多平台分发**：发布前检查 → 选择平台动作 → API 发布或复制助手 → 记录状态与历史 → 内容变化后识别需更新。
5. **自动化接入**：通过 MCP 为受控客户端提供文章、图片、发布状态等能力；写操作按权限确认并审计。

## V1 功能范围

### 写作工作区
- 文章列表支持搜索与列表/树形浏览。
- Markdown 源码编辑、实时预览、源码/分屏/预览/思维导图四种模式。
- 大纲定位与文章面板；元数据表单覆盖文章 front matter。
- 图片拖入、粘贴、文件选择或 URL 导入；按仓库规则落盘并插入相对路径引用，可设为封面。
- 自动保存、外部文件变更检测与冲突保护。

### 文章库
- 展示仓库实际文章统计、字数、图片和发布待办。
- 支持年份、分类、状态、平台筛选及全文搜索。
- 展示平台发布状态；可进入写作页或发布对话框。

### 图片库
- 图片统计、年月/引用状态/格式筛选与文件名搜索。
- 缩略图墙、引用详情、复制路径/链接、定位引用文章。
- 孤儿图识别与清理；图片变更进入 Git 工作区。

### 发布中心
- 网站 Git 工作区：变更列表、选择暂存、diff、提交信息、提交/推送和历史。
- 多平台文章状态矩阵：已发布、需更新、未发布、失败等状态从真实本地数据计算。
- 发布前检查：缺失元数据、草稿、图片问题及其他发布条件。
- 发布历史：保留发布动作、时间、平台和结果。
- 单篇发布对话框：检查区、平台行、平台动作、复制字段。
- 已接入平台按能力执行 API；未配置凭据或不支持 API 的平台提供复制助手兜底。
- 平台凭据只保存在本机系统凭据管理器。CSDN 当前属于编辑器内部接口实验接入，不承诺稳定性，不称为官方 OpenAPI。

### 站点数据
- 浏览与编辑仓库 `site/*.json`，保存时写回仓库并纳入 Git 变更。

### MCP 服务
- 服务启停、端口与访问令牌配置。
- 客户端配置生成与连接测试。
- 工具目录与权限开关。
- 调用记录、结果审计与导出；写操作按设置要求进行确认。

### 设置
- 仓库路径与扫描状态、链接策略、Git 凭据。
- 平台账户与凭据管理。
- LLM 提供方/模型/密钥配置。
- MCP 服务相关设置。
- 明暗模式、强调色、界面密度、动效和语言。

## 产品约束与非目标
- 仓库正文图片引用以相对路径为规范形态；CDN 域名作为渲染投影，不在发布时改写正文。
- 平台凭据不得写入仓库或日志。
- 发布状态必须基于真实发布记录与内容快照；不得将原型演示数据当作实际状态。
- 删除/清理应可审查、可回滚，不做不可恢复的后台静默删除。
- 不修改 Vex，不将 Vox 的领域逻辑耦合进 Vex。
- AI 生图不是 Vox 的职责；Vox 管理图片导入和引用。

## 后续增强（不阻塞当前基线）
- 更多平台适配、稳定官方 API 通道。
- 更完整的远程文章 ID/URL 与更新/删除能力。
- 发布队列持久化、计划发布与失败重试策略。
- 多仓库画像抽象与通用仓库支持。
- 体检规则的批量修复向导与治理标记体验。
