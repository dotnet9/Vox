# 安装与发布

更新于 2026-11-08，源码版本 **0.2.0-preview.4**。正式资产及发布结果以对应 [GitHub Release](https://github.com/dotnet9/Vox/releases) 为准。

## 五平台分发

| RID | 构建主机 | 安装包 | 便携压缩包 |
| --- | --- | --- | --- |
| win-x64 | Windows | `Vox-v<版本>-win-x64-setup.exe` | `Vox-v<版本>-win-x64.zip` |
| linux-x64 | Ubuntu x64 | `Vox-v<版本>-linux-x64.deb` | `Vox-v<版本>-linux-x64.tar.gz` |
| linux-arm64 | Ubuntu arm64 | `Vox-v<版本>-linux-arm64.deb` | `Vox-v<版本>-linux-arm64.tar.gz` |
| osx-x64 | macOS Intel | `Vox-v<版本>-osx-x64.dmg` | `Vox-v<版本>-osx-x64.zip` |
| osx-arm64 | macOS Intel 交叉编译 | `Vox-v<版本>-osx-arm64.dmg` | `Vox-v<版本>-osx-arm64.zip` |

每份安装包、压缩包都有同名 `.sha256`，共十份产物、十份摘要。安装包和压缩包使用同一份 NativeAOT 发布目录。Windows ZIP 解压运行 `Vox.exe`；Linux tar.gz 解压运行 `Vox`；macOS ZIP 包含带图标的 `Vox.app`。

macOS 的数字 bundle 版本取语义版本的数字部分，文件名保留 `preview` 后缀。打包检查 plist、生成 ICNS 并校验 ad-hoc 签名；这不代表已经完成 Developer ID 签名、公证或所有平台的人工使用验收。

## Windows 安装行为

`scripts/Vox.iss` 是唯一产品安装入口，负责应用文件、任务、快捷方式、注册表和安装后启动；`scripts/installer/Vox.Setup.iss` 负责本仓品牌外观。不能直接编译外观文件来制作正式安装包。

开始菜单入口始终创建；桌面快捷方式和 `.md` / `.markdown` / `.mdown` 打开候选由安装选项控制。快捷方式和完成页启动都使用安装目录作为工作目录。注册仅写当前用户的候选和右键入口，不覆盖默认应用；卸载移除自己的入口，已有配置保留。

安装 AppId 延续历史版本，使已经安装的 JIT 版本可以升级到新的原生载荷。内嵌更新日志由 `docs/更新日志.md` 生成，并在 CI 中检查逐字一致：

```powershell
python scripts/installer/embed_changelog.py --regen
python scripts/installer/embed_changelog.py
```

## 本机制作与运行验证

按 `global.json` 安装 SDK，发布脚本统一使用 PowerShell 7（`pwsh`）。Windows 还需要 Visual Studio C++ 工具链和 Inno Setup，可用 `package_win_x64.bat` 启动；Linux 需要 clang、zlib 开发文件；macOS 使用 Xcode 命令行工具。

```powershell
$voxWorkRoot = 'D:/github/temp_files/vox-release-local'
./scripts/package_windows.ps1 -WorkRoot $voxWorkRoot -OutputDirectory "$voxWorkRoot/release"
```

脚本在独立目录中执行 AOT 发布，检查 Windows PE 架构和 JIT 遗留文件，再运行实际原生窗口的 `--verify-runtime`，通过后才编译安装包并生成 ZIP。已有发布产物可用 `-SourceDirectory` 复用，仍会先检查和运行验证。

跨平台统一入口为 `scripts/publish.ps1 -Rid <RID>`，输出 `artifacts/publish/Vox.App-<RID>`，底层调用同一份 `publish-aot.ps1`。发布前清理所选输出目录，避免混入旧 JIT 文件；Windows、Linux、macOS 分别检查 PE、ELF、Mach-O 架构。

## CI 与 Release 门禁

推送 `v*` 标签或手工运行发布流程时，版本必须等于 `Directory.Build.props`。流水线先编译隔离安装器，用唯一测试 AppId、快捷方式名称和专用扩展名验证安装、可选任务与卸载，再开始五 RID 的 AOT 构建。测试不会安装或卸载用户的正式 Vox。

发布汇总步骤逐一核对十个文件的版本、非空大小、摘要格式和实际 SHA256，缺少平台、摘要不匹配或混入旧文件都会阻止创建 Release。预览版本标记为 prerelease。

```powershell
./scripts/tests/windows_setup_test.ps1
./scripts/tests/release_assets_test.ps1
./scripts/verify_release_assets.ps1 -Version 0.2.0-preview.4
```

NativeAOT 构建成功、运行自检和各操作系统的人工验收分别记录；Windows 本机运行结果不能代替 macOS / Linux 实机体验。
