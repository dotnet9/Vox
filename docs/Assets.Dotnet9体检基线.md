## 推导出的体检规则优先级

1. 缺 albums（400 条，最大缺口）→ 专辑补全向导价值最高
2. 死链 + 扩展名配对修复（58 处）
3. 孤儿图清理（527 张，删除走 git）
4. 缺 author 补全（122 条）
5. 过期/低质线索（按年份 + 字数 + 引用数）
