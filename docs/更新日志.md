# 更新日志

## 0.2.0-preview.8（2026-11-10）

- 修复「未被引用/封面」等徽章与分页当前页的文字对比度：语义色新增可读 ink 变体，八套强调色×明暗静止态全部 ≥4.5:1；强调预设 deep 加深（violet/blue/amber），orange/coral/rose 浅色主按钮文字改深色，hover 随明暗切换前景。
- 写作页源码长行改为横向滚动（与原型分屏一致，库 MarkdownEditorView.WordWrap 成对改写滚动条）；升级 CodeWF.Avalonia 12.1.5.9。
- 原型侧安装器完成步对勾不再白字压绿；toast 避让 AI 按钮；logo 引用收敛 design 自包含；门禁新增越根引用与令牌对比度矩阵检查。

## 0.2.0-preview.6（2026-11-09）

- 大纲面板切换为共享库 MarkdownOutlinePanel，与 Vex 共用同一实现；默认展开并记忆显隐状态，折叠按文档持久化（与 Vex 同口径）。
- 新增紧凑查找栏（Ctrl+F，替换编辑器自带搜索面板）：源码与即时编辑走选区高亮，阅读视图内联琥珀高亮，含当前/总数计数与大小写、全字、正则开关。
- 导图新增缩放坞（步进 ±、百分比读数、复位适配）；修复大纲空面板与点击高亮错位（构造期时序）。
- 升级 TKCode.Arc 1.0.0 与 CodeWF.Avalonia 12.1.5.6；原型侧配色全令牌化并补齐导图画布交互。

## 0.2.0-preview.5（2026-11-08）

- 大纲行高、层级编号、当前章节高亮与搜索清除参照 Vex 对齐。
- 预览支持文字选择、Ctrl+C、右键复制选区与全文；修复表格中的本地图片显示。
- 标题栏图标缩小并水平对齐，语言图标与下拉菜单沿用 Vex，移除右侧重复的 MCP 服务入口。
- 升级 CodeWF.Avalonia 12.1.5.4，保持可空类型检查与 C# 预览特性支持。

## 0.2.0-preview.4（2026-11-08）

- Windows 安装入口参照 Vex 补齐开始菜单、可选桌面快捷方式与 Markdown 打开候选，启动时使用应用目录；保留原有配置，不更改系统默认打开程序。
- 正式 Release、CI 和本机发布共用五平台 NativeAOT 配方，检查目标架构并拒绝混入 JIT 载荷；Windows 分发前运行实际原生窗口验证。
- 五个平台同时提供安装包与便携压缩包：Windows EXE / ZIP、Linux DEB / tar.gz、macOS DMG / 含 `.app` 的 ZIP，十份产物逐一生成并核对 SHA256。
- macOS 补齐应用图标、Markdown 文档类型和数字版 bundle 版本；ad-hoc 签名失败停止发布。
- 安装器内嵌日志改为来自本仓库真实更新日志，支持 Vox 的版本标题；新增隔离安装、可选任务、卸载清理和发布清单异常回归。

## 0.2.0-preview.3（2026-11-08）

- 大纲参照 Vex 使用虚拟化列表、层级编号、缩进和当前章节样式，增加标题筛选及父级上下文，清除筛选后恢复折叠状态。
- 将大纲选中与显式导航分离，支持鼠标、Enter / Space 重复激活和左右键折叠展开，修复离屏及同名标题的跳转定位。
- 阅读位置同步当前章节，不反向触发导航或抢正文焦点；当前行状态采用可回收的直接订阅，兼容 NativeAOT。
- 更新 README 与桌面操作手册，保留历史原型手册，增加 16 张真实应用截图、3 段连续交互动图和可复现采集入口。
- 补充层级筛选、折叠恢复、虚拟化、重复导航与阅读跟随回归；同步四语言版本文案，保持可空类型与 C# 预览特性支持。

## 0.2.0-preview.2（2026-11-08）

- 升级正式 CodeWF.Avalonia/Toolkit NuGet 包、Arc 0.4 预览版与 TextMate 3 预览版，移除旧候选包源码配置。
- 修正可空 YAML 字段、凭据读取、字体继承及编辑器空文本处理，将可空警告作为编译错误，保持 C# 预览特性支持。
- 增加实际 NativeAOT 窗口、四种语言、七个页面、明暗主题和可空设置往返验证，并隔离验证配置。
- 修复 NativeAOT 下博客 YAML 反射解析失败，显式映射元数据并保留可空字段、字符串类型与嵌套自定义键；消除 MCP JSON 数组的泛型反射序列化路径。
- 补齐 Arc 下写作文章列表与列表项的基础模板，修复文章总数正常但列表空白的问题；运行验证检查真实标题可见并驱动窗口消息循环。
- 文章导航参照 Vex 的紧凑单行、图标、目录标签与选中条；列表和年/月树共用虚拟化宿主，保留折叠状态，支持整行展开和键盘左右导航，并增加 1001 篇文章的滚动回收门禁。
