## 关键页面布局

### 写作页（核心）

三区布局，两侧可收起：

```text
┌──────────────────────────────────────────────────┐
│ [新建文章] [文章列表侧栏（可收起）]                  │
│ ┌──────────────────────────────┬───────────────┐ │
│ │  编辑器 / 预览 分屏            │  文章面板       │ │
│ │  （纯编辑 / 分屏 / 纯预览切换） │  页签：元数据   │ │
│ │  文件名栏 + 发布状态徽标        │        大纲    │ │
│ │                              │        图片    │ │
│ └──────────────────────────────┴───────────────┘ │
└──────────────────────────────────────────────────┘
```

- 编辑/预览比例可拖；大纲跳转双向联动（预览点击 ↔ 源码定位）
- 文件名栏右侧发布状态徽标（各平台彩点），点击打开发布对话框
- 图片页签：拖入即入库并插引用；本篇缩略图；设为封面

### 文章库页

浏览态与编辑态合一：列表即主页，双击进入写作页编辑态（同页切换，不开新窗口）；顶部统计条（文章数/字数/图片数/待推送）；表格含各平台状态列（●已同步 ◐需更新 ○未发布 ✕失败）。

### 发布中心页

- **网站（git）标签**：GitHub Desktop 式两栏——左 Changes 勾选暂存 + diff 预览（并排/统一切换、图片修改前后对比、右键放弃更改），右 Summary/Description 提交面板 + 历史；push 即网站发布。
- **多平台标签**：文章 × 平台状态矩阵（状态 = 本地内容快照 hash 对比平台已发布快照：已同步/需更新/未发布/失败）；点状态点或「发布…」进发布对话框。
- **发布前检查标签**：发布阻塞项分组（待推送提交、失效图片引用、缺 author、草稿、无封面/简述）。
- **发布对话框**：单篇 × 五平台——该篇检查项 + 动态摘要、每平台状态/说明/按通道动作（git 去 push、api 直发/重试/更新凭据、copy 复制助手）、复制字段 chips（标题/描述/封面 URL/Markdown/公众号 HTML/富文本）。
- **平台账户**（设置页段 + 弹层）：公众号/博客园/CSDN 凭据存系统凭据管理器；配置即启用 API 直发，未配置降级复制助手。

## 设计原型（2026-10-23 重绘，Arc 品牌风；2026-10-25 五视图改版）

软件原型为单文件应用形态（内置视图切换，模拟真实应用），安装器/卸载器按平台独立成页：

```text
design/
├── assets/                  ← 共享：tokens.css（Arc 视觉令牌）· app.css · installer.css · fonts/
├── Vox软件原型.html           ← 5 视图（写作/文章库/发布中心/站点数据/设置）
│                                + 3 弹层（新建文章向导 / 图片入库 / 发布对话框）+ 平台账户弹层
├── 安装器-Windows.html  卸载-Windows.html   ← Arc 品牌自绘向导（Windows 惯例）
├── 安装器-macOS.html    卸载-macOS.html     ← 标准 DMG 拖拽安装 / 拖废纸篓卸载（平台惯例）
└── 安装器-Linux.html    卸载-Linux.html     ← 系统软件中心页面（GNOME Software 风，平台惯例）
```

评审方式：直接双击打开。软件原型以**桌面窗体**呈现（自绘标题栏 + 窗体投影 + 桌面舞台背景），内部切视图即模拟真实应用；Windows 安装/卸载为 460×320 紧凑向导（可点击步进，含安装模拟）；macOS 为 DMG 拖拽演示与"拖入废纸篓"演示（可交互）；Linux 为软件中心页面（安装/移除按钮与确认对话框均可点）。每个页面可切明暗与四套 Arc 强调色。

演示数据口径：仓库已完成治理（37 篇文章 / 259 图，front matter 内联），原型演示的是治理后的日常维护与发布场景（发布矩阵、发布对话框、检查项均按此口径取数）；治理前的基线数据留档于 [Assets.Dotnet9 体检基线](Assets.Dotnet9体检基线.md)。

品牌资产统一引用根目录 `../logo.svg`（决策 D12）。视觉令牌在正式实现中由 TKCode.Arc 主题原生接管，原型 CSS 仅为评审近似。
