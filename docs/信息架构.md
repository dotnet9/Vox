# 信息架构（V1 基准）

状态：**已冻结为当前实现基准（2026-10-31）**。视觉与交互以 [design/Vox.html](../design/Vox.html) 为准；实现以 Avalonia 页面为准。原型中的演示数据只用于说明布局，不得复制为业务数据。

## 主窗口与导航

主窗口采用 Arc 视觉体系：自绘标题栏、左侧可折叠导航、页面宿主、统一弹层与 Toast。导航默认展开；窄屏或用户主动操作时可折叠。

| 导航 | 页面职责 | 实现 |
| --- | --- | --- |
| **写作**（默认） | 文章列表 + Markdown 源码/预览/思维导图四态 + 元数据/大纲/图片侧栏；自动保存、发布状态入口 | `WritePage` |
| **文章库** | 全库统计、筛选、搜索、平台状态、分页，进入文章编辑或发布 | `LibraryPage` |
| **图片库** | 图片统计、年月/引用/格式筛选、缩略图墙、引用详情、孤儿图清理与图片入库 | `ImagesPage` |
| **发布中心** | 网站 Git 工作区、多平台文章状态矩阵、发布前检查、发布历史 | `PublishPage` |
| **站点数据** | `site/*.json` 文件导航与结构化编辑 | `SiteDataPage` |
| **MCP 服务** | 服务配置、客户端接入、工具目录、调用审计 | `McpPage` |
| **设置** | 写作保存、仓库、链接策略、Git、平台账户、LLM/MCP、外观与关于 | `SettingsPage` |

## 核心交互约定

### 写作
- 左侧文章列表、中间编辑/预览/思维导图、右侧文章面板构成工作区；两侧可收起，分隔线可拖动。
- 编辑模式：源码、分屏、预览、思维导图；预览与大纲可联动定位。
- 文章面板包含元数据、大纲、图片；图片导入后写入仓库并插入相对路径引用。
- 自动保存以磁盘为唯一真值；文件名栏显示当前文章及各发布通道状态，点击状态可进入发布对话框。

### 文章库与图片库
- 列表、筛选和统计全部读取仓库扫描结果与发布状态，不使用原型中的固定数字。
- 文章库负责文章级查找、状态判断与跳转；图片库负责图片资产查找、引用关系与清理。
- 删除和修复操作遵循可审查、可回滚原则，涉及仓库文件变更时纳入 Git 工作区。

### 发布中心
- **网站**：Git Changes、diff、提交信息、提交/推送与历史。
- **多平台**：文章 × 平台状态矩阵；状态由本地内容快照与平台记录计算，不以静态演示值为准。
- **发布前检查**：集中展示发布阻塞项与提醒。
- **发布历史**：展示各平台发布动作与结果。
- 单篇发布对话框展示检查项、五个通道状态/动作和复制字段；未配置 API 凭据时降级为复制助手。
- CSDN 当前使用编辑器内部接口，标记为实验性、非官方能力；不得在界面或文档中称为官方 OpenAPI。

### 站点数据、MCP 与设置
- 站点数据页以仓库中的实际 JSON 文件为准。
- MCP 页分服务、客户端、工具、审计四个子页；写操作遵循权限与确认策略。
- 平台凭据保存在本机系统凭据管理器，不进入仓库。

## 原型与实现关系

- 主原型：`design/Vox.html`；共享样式：`design/assets/tokens.css`、`design/assets/app.css`。
- 正式 UI：`src/Vox.App/Views/Pages/` 与 `src/Vox.App/Dialogs/`。
- 原型用于视觉层级、信息组织与交互流程评审；Avalonia 实现负责接入真实仓库、凭据、Git、发布服务和审计数据。
- 原型与实现不一致时，先判断是否为原型演示数据/静态限制；确认是产品行为差异后，再同步修改两端并更新本文。
- Vex 是独立产品，不属于 Vox 的实现范围。
