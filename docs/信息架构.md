# 信息架构（M1）

状态：共识草案（2026-10-23）。主窗口 = 左侧窄导航栏 + 内容区，Arc 组件体系。

## 导航结构

| 导航项 | 职责 | 优先级 |
| --- | --- | --- |
| **写作**（默认页） | 新建文章向导 + 编辑视图 | P0 |
| **文章库** | 全库浏览与筛选，双击进入写作页编辑态 | P0 |
| **图片库** | 缩略图网格、孤儿图、入库、链接复制 | P0 |
| **体检** | 问题列表、修复向导、治理标记 | P0 |
| **同步** | git 改动、提交推送、历史 | P0 |
| **站点数据** | site/*.json 表单（仅 zh-CN） | P1 |
| **设置** | 仓库、链接策略、凭据、外观 | P1 |

## 关键页面布局

### 写作页（核心）

三区布局，两侧可收起：

```text
┌──────────────────────────────────────────────────┐
│ [新建文章] [文章列表侧栏（可收起）]                  │
│ ┌──────────────────────────────┬───────────────┐ │
│ │  编辑器 / 预览 分屏            │  文章面板       │ │
│ │  （纯编辑 / 分屏 / 纯预览切换） │  · 封面缩略图   │ │
│ │                              │  · 元数据表单   │ │
│ │                              │  · 预览大纲     │ │
│ │                              │  · 图片面板     │ │
│ └──────────────────────────────┴───────────────┘ │
└──────────────────────────────────────────────────┘
```

- 编辑/预览比例可拖；大纲跳转双向联动（预览点击 ↔ 源码定位）
- 图片面板：拖入即入库并插引用；最近图片列表；设为封面

### 文章库页

浏览态与编辑态合一：列表即主页，双击进入写作页编辑态（同页切换，不开新窗口）；顶部统计条（文章数/字数/图片数/体检问题数）。

### 图片库页

缩略图网格 + 分组（年月/所属文章）+ 筛选（孤儿图）；选中图可复制 CDN 链接/相对路径、查看引用文章、删除（走 git）。

### 体检页

问题按规则分组列出 → 点开看明细与修复建议 → 单条修复或批量修复；专辑补全向导与"重写/退役/删除"治理标记入口在此。

### 同步页

git 语义化改动列表（文章/图片聚合展示，非文件名列表）、提交信息（自动建议）、一键提交并推送、历史。

## 旧设计原型处置

`design/` 下旧原型（Vex 风格，7 页）：

| 旧页 | 处置 |
| --- | --- |
| Articles.html | → 文章库页演进 |
| ArticleDetail.html | → 写作页编辑态演进 |
| Audit.html | → 体检页演进 |
| Vox.html（概览仪表盘） | 砍，价值并入文章库顶部统计条 |
| Publishing.html（发布清单） | 移出 M1，M2 回归 |
| Appearance.html（外观设置） | 瘦身为设置页，主题交给 Arc 强调色体系 |
| index.html（原型导航壳） | 无对应，废弃 |

旧原型的 tokens/palettes/density 自研设计系统机制由 Arc 主题原生替代；原型仅作页面布局与交互流程参考。
