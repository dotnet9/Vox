# 信息架构（M1）

状态：共识草案（2026-10-23）。主窗口 = 左侧窄导航栏 + 内容区，Arc 组件体系。

## 导航结构

| 导航项 | 职责 | 优先级 |
| --- | --- | --- |
| **写作**（默认页） | 新建文章向导 + 编辑视图 | P0 |
| **文章库** | 全库浏览与筛选，双击进入写作页编辑态 | P0 |
| **图片库** | 缩略图网格、孤儿图、入库、链接复制 | P0 |
| **体检** | 问题列表、修复向导、治理标记 | P0 |
| **同步** | git 改动、提交推送、历史 | P0 |
| **站点数据** | site/*.json 表单（仅 zh-CN） | P1 |
| **设置** | 仓库、链接策略、凭据、外观 | P1 |

## 关键页面布局

### 写作页（核心）

三区布局，两侧可收起：

```text
┌──────────────────────────────────────────────────┐
│ [新建文章] [文章列表侧栏（可收起）]                  │
│ ┌──────────────────────────────┬───────────────┐ │
│ │  编辑器 / 预览 分屏            │  文章面板       │ │
│ │  （纯编辑 / 分屏 / 纯预览切换） │  · 封面缩略图   │ │
│ │                              │  · 元数据表单   │ │
│ │                              │  · 预览大纲     │ │
│ │                              │  · 图片面板     │ │
│ └──────────────────────────────┴───────────────┘ │
└──────────────────────────────────────────────────┘
```

- 编辑/预览比例可拖；大纲跳转双向联动（预览点击 ↔ 源码定位）
- 图片面板：拖入即入库并插引用；最近图片列表；设为封面

### 文章库页

浏览态与编辑态合一：列表即主页，双击进入写作页编辑态（同页切换，不开新窗口）；顶部统计条（文章数/字数/图片数/体检问题数）。

### 图片库页

缩略图网格 + 分组（年月/所属文章）+ 筛选（孤儿图）；选中图可复制 CDN 链接/相对路径、查看引用文章、删除（走 git）。

### 体检页

问题按规则分组列出 → 点开看明细与修复建议 → 单条修复或批量修复；专辑补全向导与"重写/退役/删除"治理标记入口在此。

### 同步页

git 语义化改动列表（文章/图片聚合展示，非文件名列表）、提交信息（自动建议）、一键提交并推送、历史。

## 设计原型（2026-10-23 重绘，Arc 品牌风）

旧 Vex 风格原型（index 导航壳 + 7 页）已删除（git 历史可查）。新原型为 7 个独立 HTML，**无导航壳**——软件原型是单文件应用形态（内置视图切换，模拟真实应用），安装器/卸载器按平台独立成页：

```text
design/
├── assets/                  ← 共享：tokens.css（Arc 视觉令牌）· app.css · installer.css · fonts/
├── Vox软件原型.html           ← 7 视图（写作/文章库/图片库/体检/同步/站点数据/设置）
│                                + 3 弹层（新建文章向导 / 图片入库 / 专辑补全）
├── 安装器-Windows.html  卸载-Windows.html   ← Arc 品牌自绘向导（Windows 惯例）
├── 安装器-macOS.html    卸载-macOS.html     ← 标准 DMG 拖拽安装 / 拖废纸篓卸载（平台惯例）
└── 安装器-Linux.html    卸载-Linux.html     ← 系统软件中心页面（GNOME Software 风，平台惯例）
```

评审方式：直接双击打开。软件原型以**桌面窗体**呈现（自绘标题栏 + 窗体投影 + 桌面舞台背景），内部切视图即模拟真实应用；Windows 安装/卸载为 460×320 紧凑向导（可点击步进，含安装模拟）；macOS 为 DMG 拖拽演示与"拖入废纸篓"演示（可交互）；Linux 为软件中心页面（安装/移除按钮与确认对话框均可点）。每个页面可切明暗与四套 Arc 强调色。数据取自 [Assets.Dotnet9 体检基线](Assets.Dotnet9体检基线.md)（536 篇 / 4203 图 / 400 缺专辑等），保证评审语境真实。

品牌资产统一引用根目录 `../logo.svg`（决策 D12）。视觉令牌在正式实现中由 TKCode.Arc 主题原生接管，原型 CSS 仅为评审近似。
