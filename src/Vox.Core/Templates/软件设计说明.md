#### 接口：更新用户信息

> 允许已授权的用户通过此接口更新自己的信息。

- **URL**：/api/user
- **Method**：PUT
- **需要登录**：是
- **需要鉴权**：是

| 参数 | 类型 | 约束 |
| --- | --- | --- |
| first_name | String | 1 到 30 个字符 |
| last_name | String | 1 到 30 个字符 |

> 注意：id 和 email 字段是只读属性，不允许通过此接口修改。

### 请求示例

```
PUT /api/user
{ "first_name": "三", "last_name": "张" }
```
